# Telegram ИИ-бот (как ChatGPT)

Умеет:
- отвечать на сообщения и помнить контекст диалога (последние 20 сообщений);
- генерировать картинки: «нарисуй ...» или `/image ...`;
- создавать файлы (код, md, csv, txt...) и присылать их документом: «сделай файл ...»;
- понимать присланные фото (если модель поддерживает картинки) и текстовые файлы;
- `/models`, `/model <id>` — смотреть и переключать модель, `/reset` — очистить историю.

## 1. Токены
1. Telegram: напишите @BotFather → `/newbot` → получите токен.
2. Ключ AgentRouter у вас уже есть.

## 2. Проверка ключа (локально, по желанию)
```
pip install -r requirements.txt
copy .env.example .env      # и впишите токены в .env
python check_api.py
```
Скрипт покажет доступные модели и работает ли генерация картинок.
Впишите нужную модель в `CHAT_MODEL`.

## 3. Запуск на bothost
1. Создайте бота → язык Python.
2. Загрузите `bot.py` и `requirements.txt` (файл `.env` с ключами НЕ загружайте).
3. Главный файл: `bot.py`.
4. В переменных окружения задайте `TELEGRAM_BOT_TOKEN`, `API_KEY`, `API_BASE_URL`,
   `CHAT_MODEL`, при необходимости `IMAGE_MODEL` и `ALLOWED_USERS`.
5. Запустите и напишите боту `/start`.

## Замечания
- AgentRouter ориентирован на ИИ-агентов для программирования. Если он не отдаёт
  модель для картинок, `/image` выдаст ошибку, а всё остальное продолжит работать.
  Тогда в `IMAGE_MODEL` можно указать другую модель из `/models`.
- История хранится в памяти и сбрасывается при перезапуске.
- Чтобы бот не расходовал ваш ключ на чужих людей, укажите свой id в `ALLOWED_USERS`
  (узнать id можно у @userinfobot).
