# Telegram ИИ-бот на Claude Code + AgentRouter

Бот передаёт сообщения в официальный Claude Code (`claude -p`), а тот обращается к AgentRouter.
У каждого чата своя папка и своя сессия, поэтому бот помнит контекст.

Умеет:
- отвечать на сообщения с учётом истории диалога;
- создавать файлы (код, документы, CSV, HTML, SVG) и присылать их документом;
- читать присланные фото и файлы.

Не умеет: генерировать растровые картинки (Claude этого не делает), но может нарисовать SVG.

Claude Code в боте работает только с файлами в папке чата: Bash, интернет и другие инструменты отключены.

## Переменные окружения (bothost → «Переменные»)
- `API_KEY` — ключ AgentRouter (`sk-...`)
- `API_BASE_URL` — `https://agentrouter.org` (`/v1` в конце можно не убирать, бот уберёт сам)
- `CHAT_MODEL` — необязательно, например `claude-sonnet-4-5-20250929`
- `ALLOWED_USERS` — ваш Telegram id, чтобы ботом пользовались только вы (рекомендуется)
- токен бота — поле «Токен» в bothost

## bothost
Нужен собственный Dockerfile: включите «Использовать собственный Dockerfile».
Образ ставит Node.js, Claude Code и Python-зависимости и запускает бота от обычного пользователя.

## Локальный запуск
Нужны Python 3.10+, Node.js 18+ и `npm i -g @anthropic-ai/claude-code`.
```
pip install -r requirements.txt
python bot.py
```
